# Wireframe Style Backup

This folder contains the complete, untouched copy of the website in its original wireframe style (as created based on `booking-homepage.jpg`), saved on Nov 26, 2026.

### Preserved Files:

- `+page.svelte`: Original single-page layout
- `app.css`: Original wireframe CSS variables & styling
- `lib/`: All original components and data

### Note on Theme Switching:

The active website now includes a live Theme Switcher in the top bar:

- **LVM Official Style** (default, based on `https://atputa.lvm.lv/en/`)
- **Wireframe Style** (original minimalist style)

You can switch between them at any time with a single click, or restore these backup files directly if desired.
